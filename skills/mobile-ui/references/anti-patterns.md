# Anti-generic design review

These are heuristics, not bans. A pattern is acceptable when the product/context makes it the best choice.

## Template signatures
- title + subtitle + same-size cards repeated down the screen
- every group floating in a rounded rectangle
- generic blue/purple/pink gradient standing in for brand identity
- identical corner radius and shadow everywhere
- muted gray text hierarchy so subtle that priorities disappear
- icon + label + chevron repeated even when rows have different semantics
- huge empty hero area on a task-focused mobile screen
- dashboard metrics for products whose primary job is not monitoring
- generic "AI" sparkles, glow, or orb motifs unrelated to subject

## Flatness signatures
- canvas, content, controls, and chrome share the same visual plane without intentional hierarchy
- all text uses nearly the same style
- dividers/spacing/grouping fail to communicate relationships
- interactive and static elements are visually indistinguishable

## Over-design signatures
- glass/blur on every layer
- multiple accent colors competing for action priority
- shadows/elevation on every container
- animation on every tap/appearance
- custom controls that are harder to recognize than native ones
- decoration that adds no product-specific meaning

## Replacement test
Hide the logo and replace the copy with another app category. If the design still fits perfectly, strengthen product-specific identity.
