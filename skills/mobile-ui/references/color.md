# Color

Build color around roles and hierarchy.

## Suggested roles
- canvas/background
- primary surface
- secondary/elevated surface
- primary content
- secondary content
- separator/border when needed
- accent/action
- semantic success/warning/error/info
- selection/focus

## Rules
- Start from the product's tone and content, not a default blue/purple gradient.
- Use accent color to direct attention; too many accents destroy hierarchy.
- Verify light, dark, increased-contrast/high-contrast contexts where applicable.
- Use semantic/system-adaptive colors when they improve platform integration.
- Never rely on hue alone to communicate status.
- Check text/control contrast with authoritative accessibility guidance appropriate to the platform.
- Avoid pure brand-color saturation everywhere; brand identity can come from composition, type, imagery, shape, and motion too.
