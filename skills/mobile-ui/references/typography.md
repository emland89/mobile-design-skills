# Typography

Typography carries product personality and hierarchy while remaining readable and scalable.

## System
Define semantic roles rather than per-screen arbitrary sizes:
- display/hero only when the content earns it
- screen/title
- section heading
- body
- supporting/meta
- label/control
- numeric/data roles where needed

## Rules
- Use size, weight, width/design, case, line height, and spacing intentionally; do not rely on size alone.
- Preserve Dynamic Type/font scaling and avoid brittle fixed heights.
- Use monospaced digits for changing aligned numbers when supported.
- Prefer platform system typography when it provides the intended voice; custom fonts must earn bundle/performance/accessibility complexity.
- Do not make every heading bold merely because it is a heading.
- Limit the number of competing type treatments.
- Validate truncation and long localized text.
