# iOS / iPadOS visual grammar

Use current Apple HIG as authority; platform visuals evolve.

- Keep content prominent and system chrome understandable.
- Prefer semantic typography and Dynamic Type-compatible treatments.
- Use system/adaptive colors and materials when they support hierarchy and appearance changes.
- Liquid Glass/material effects are a layer language, not a blanket aesthetic. Use them where they clarify chrome, context, or hierarchy and maintain contrast.
- Standard controls, symbols, sheets, toolbars, tab/navigation chrome should remain recognizable even when branded.
- Distinctiveness can come from content composition, typography, color system, imagery, data visualization, shape, and purposeful motion without replacing native interaction conventions.
- Test light/dark, increased contrast, Reduce Motion, large text, iPhone/iPad/resizable contexts.
- Do not equate default SwiftUI appearance with the full range of native iOS design.
