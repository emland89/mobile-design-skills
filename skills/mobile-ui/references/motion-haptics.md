# Motion and haptics

## Motion hierarchy
1. direct-manipulation response
2. spatial continuity/navigation orientation
3. state-change explanation
4. attention guidance
5. decorative delight

The lower items must not interfere with the higher ones.

## Rules
- Animate relationships, not everything that changed.
- Preserve spatial continuity when an object expands, moves, or changes context.
- Use coherent timing/physics rather than unrelated animation values.
- Avoid long entrance choreography on frequently visited screens.
- Respect reduced-motion settings; substitute fades/state changes where movement is not necessary.
- Haptics reinforce a meaningful selection, impact, boundary, warning, or success; they never carry the only feedback.
- Do not fire haptics for every tap.
