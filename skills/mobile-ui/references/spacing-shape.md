# Spacing and shape

## Spacing
- Use a small rhythm/token set for consistency, then apply optical correction where content requires it.
- Separate unrelated groups more than related items.
- Internal component spacing should reveal structure, not merely match a universal token.
- Avoid uniform vertical gaps that erase hierarchy.

## Shape
- Shape can signal containment, affordance, selection, brand character, or hierarchy.
- Do not put every element inside a rounded rectangle.
- Do not apply one radius mechanically to buttons, cards, sheets, tags, images, and nav elements.
- Prefer native control silhouettes for conventional controls unless customization retains clear affordance.
- Expressive shape should be concentrated where it provides identity or state, not scattered as decoration.
