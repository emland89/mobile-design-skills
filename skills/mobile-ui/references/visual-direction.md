# Visual direction

A visual direction is a product-specific thesis, not a mood-board adjective.

## Derive it from
- subject/domain artifacts, environments, language, data, and rituals
- target audience and level of expertise
- emotional goal of the task
- existing brand/product assets worth preserving
- platform context

## Define
1. 2-4 attributes with consequences (e.g. "editorial" -> strong type-led hierarchy, generous margins, restrained surfaces).
2. One signature idea or recurring motif tied to the product.
3. One thing deliberately avoided.
4. Quiet supporting system so the signature is not competing with everything.

## Test
Could the direction be transplanted unchanged to a banking, fitness, AI-chat, recipe, and travel app? If yes, it is too generic.
