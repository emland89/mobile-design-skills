# Wear OS visual grammar

Use current Wear OS and Material guidance as authority.

- Compose for compact and often round displays; do not crop or shrink a phone layout.
- Build a strong focal hierarchy for seconds-long viewing and vertical movement.
- Respect Wear OS components, scrolling/rotary feedback, Tiles, complications, and notification surfaces rather than forcing phone visual grammar.
- On glanceable surfaces, show only essential information and make interactive containers clearly functional rather than decorative.
- Use shape, color, type, imagery, and motion selectively so the product is recognizable without overwhelming a tiny display.
- Protect readable text and adequate targets/spacing; reduce scope before reducing usability.
- Allow Wear OS to look native even when the iOS/watchOS version expresses the same brand differently.
