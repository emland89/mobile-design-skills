# Android large-screen visual grammar

Use current Android adaptive and Material guidance as authority.

- Recompose hierarchy for tablets, foldables, and large/resizable windows; do not simply increase whitespace or stretch phone cards.
- Let navigation and pane structure visually transform with the adaptive UX model.
- Use canonical multi-pane structures when they clarify relationships, while keeping product-specific composition inside them.
- Treat posture, window size, edge-to-edge system UI, keyboard/pointer/stylus, and focus states as part of the visual system when relevant.
- Preserve Material/Android recognizability without copying Google's product aesthetic; brand can live in semantic color, type, imagery, shape, content, and signature motion.
