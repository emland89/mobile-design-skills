# Surfaces, materials, and depth

Depth is information about layer and relationship.

Use a distinct surface/material when it communicates one of:
- content vs chrome
- transient vs persistent layer
- selected/focused vs background
- draggable/floating vs embedded
- foreground context while preserving awareness of content behind it

## Rules
- Prefer spacing and tonal contrast before adding shadows.
- Use blur/translucency only where background context and legibility remain useful.
- Stronger opacity/material can improve contrast; thinner/translucent material can preserve context.
- Avoid stacking multiple elevated/glass surfaces with equal prominence.
- Platform-provided materials should be used in ways consistent with the platform's current visual grammar.
- Decorative "glass everywhere" is not depth; it often erases hierarchy.
