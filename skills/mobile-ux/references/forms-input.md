# Forms and input

- Ask only for information needed now; defer optional fields.
- Use input types, autofill, scanning, pickers, or system capabilities when they reduce effort and errors.
- Keep labels persistent when losing them would force recall.
- Explain formatting requirements before or at entry, not only after failure.
- Validate at a time that helps correction without interrupting normal entry.
- Preserve input after validation, network, auth, or navigation errors.
- Make submit state and progress clear; prevent accidental duplicate submission when consequential.
- For long forms, group by user meaning and consider saving progress.
- Account for keyboard occlusion, focus movement, return-key behavior, and hardware keyboards.
- Destructive clearing/reset deserves proportional protection.
